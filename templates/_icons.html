{# Inline SVG icon sprite. Replaces the Font Awesome 6.4.0 CDN stylesheet, which shipped the entire icon set over a render-blocking third-party request for about twenty glyphs, and also replaces the loose unicode glyphs (☰ ✕ ▾ ★) that were mixed in alongside it on the same screens. One grammar throughout: 24×24 box, 1.5 stroke, round cap and join, no fills. Usage: Size with the .icon / .icon-sm / .icon-lg classes, never with width/height attributes — currentColor and em-sizing keep icons aligned to their label. #}
